Formula and working principle

1. Resolution

For an 8-bit DAC:

Resolution = Vref / 256

2. Ideal output voltage

Vout = Digital code × Vref / 256

Digital code range: 0–255

3. Example

For code 128 and Vref = 5 V:

Vout = 128 × 5 / 256 = 2.5 V

Note: This is an ideal 8-bit DAC simulation for teaching. Real DAC ICs may use different output scaling, offset, gain and endpoint conventions. Actual lab readings will depend on the DAC module and circuit used.
