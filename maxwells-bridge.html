Maxwell’s Bridge

Interactive balance-condition learning module

1. Bridge concept

Maxwell’s inductance-capacitance bridge can be used to determine an unknown coil’s inductance and resistance by comparison with a standard capacitor and resistors.

This page demonstrates the ideal balance equations; it is not a real circuit instrument or hardware controller.

2. Enter known values

For the common Maxwell bridge balance form used in this teaching calculator:

Lx = R2 × R3 × C4
Rx = (R2 × R3) / R4
Unknown coil resistance, Rₓ
1000 Ω
Unknown coil inductance, Lₓ

Check your course convention: Bridge-arm labels and balance equations can differ between diagrams and textbooks. Verify these equations against your laboratory manual before using the page for assessment.

3. Learning checkpoints

  1. Set the known resistor and capacitor values.
  2. Calculate the unknown coil resistance and inductance using the displayed balance equations.
  3. Change one component at a time and observe how the calculated unknown values change.
  4. Record the values and compare them with the theoretical result in your lab record.

Try it

Set R₂ = 1000 Ω, R₃ = 1000 Ω, R₄ = 1000 Ω and C₄ = 0.1 µF. Then change C₄ to 0.2 µF. What happens to the calculated inductance?
